# Bank Management System

A command-line Bank Management System developed in Python as a Class 12 school project. This project was built to explore basic programming concepts, object-oriented programming, data management, and administrator authentication.

## Features

- **Admin Account Creation:** Create an administrator account with password requirements.
- **Admin Login:** Authenticate before accessing management features.
- **Create Customer Accounts:** Store account numbers, customer details, and balances.
- **Update Customer Accounts:** Modify contact information, address, and balance.
- **View Account Details:** Search for a customer account by account number.
- **View Customer Database:** Display all stored customer records.
- **Delete Customer Accounts:** Remove customer records.
- **Persistent Storage:** Save customer data using Pandas and Python pickle files.

## Technologies Used

- Python
- Pandas
- Object-Oriented Programming (OOP)
- File Handling
- Pickle Serialization
- `datetime` and `pytz`

## How to Run

1. Install Python 3.
2. Install the required dependencies:

   ```bash
   pip install pandas pytz
   ```

3. Run the Python script:

   ```bash
   python main.py
   ```

4. Follow the menu displayed in the terminal to create an administrator account and manage customer records.

## Data Storage

The application uses local files to store its data:

- `Customer_Data.pkl` — customer account records.
- `super_admin.bat` — serialized administrator credentials.

These files are generated by the application during use.

## Limitations

This project was developed for educational purposes. It is not suitable for real banking operations or storing real customer information. Its authentication and data-storage mechanisms are not designed to meet modern security requirements.

## Project Background

This project was developed during Class 12 as an exploration of Python programming, data manipulation, file handling, and object-oriented design. This repository preserves the original project for learning and historical reference.
